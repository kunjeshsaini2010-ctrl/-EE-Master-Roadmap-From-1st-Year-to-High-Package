# ⚡ Electrical Engineering Ultimate Roadmap

A complete, production-ready, interactive learning roadmap for Electrical Engineering students. Designed with premium Apple-style glassmorphism UI, smooth 120Hz liquid animations, and accessible Hinglish content.

## 🚀 Features

- **🎓 Complete B.Tech Timeline**: Semester 1 to 8 subjects, strategies, and outcomes.
- **📚 Comprehensive Subject Library**: Detailed breakdown of Core Subjects, IoT, Arduino, and ESP32.
- **🛠️ 100+ Project Concepts**: From basic DIY Arduino projects to Advanced MATLAB/Simulink industry implementations. Filterable by difficulty.
- **📊 Interactive Dashboard**: Visual skill requirements and salary progression charts using Chart.js.
- **🏛️ Top Colleges Section**: Insights into top IITs and NITs for core engineering.
- **💼 Placement & Interview Prep**: Core technical questions and resume building tips.
- **🌓 Auto/Manual Theme Engine**: Seamless Dark and Light mode transitions.
- **📱 PWA Ready**: Installable as a native app on mobile and desktop with offline support.
- **⚡ Performance Optimized**: Vanilla HTML/CSS/JS. No React, No build tools, GPU-accelerated CSS animations.
